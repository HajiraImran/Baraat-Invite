# Baraat invitation - Bride's family version (Talha)

## Run
```bash
npm install
npm run dev
```

## Edit details
Open `src/App.jsx` and change the `CONFIG` block at the top (names, hosts, venue, schedule).
IMPORTANT: date, venue, address and schedule are PLACEHOLDERS. Replace them with the real Baraat details.

## Guest links
Add `?guest=Name` to the link, for example
`https://your-site.vercel.app/?guest=Uncle%20Ahmed`

## Deploy
Push to GitHub and import the repo in Vercel (framework: Vite), or run `vercel --prod`.
No image files are needed for this design.
